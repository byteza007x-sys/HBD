# เว็บสุขสันต์วันเกิด

เปิดเว็บได้ที่ `index.html` หรือถ้าใช้ XAMPP ให้เข้า:

```text
http://localhost/happyfan/
```

หน้าแรกจะเป็นจดหมายกระดาษเก่า กดที่จดหมายแล้วดอกไม้กระดาษจะบานขึ้น พร้อมเปิดข้อความวันเกิด เพลง และปุ่มลงไปดูคลิป

## ใส่คลิป

นำไฟล์วิดีโอไปวางในโฟลเดอร์ `assets` แล้วตั้งชื่อไฟล์เป็น:

```text
hbd.mp4
```

## ใส่เพลง

นำไฟล์เพลงไปวางในโฟลเดอร์ `assets` แล้วตั้งชื่อไฟล์เป็น:

```text
birthday-song.mp3
```

ถ้าเบราว์เซอร์บล็อกเสียง ให้กดปุ่ม `เล่นเพลง`

เพลงพื้นหลังจะหยุดอัตโนมัติเมื่อเริ่มเล่นคลิปหรือเสียงอวยพร

## ใส่เสียงอวยพร

นำไฟล์เสียงอวยพรไปวางในโฟลเดอร์ `assets` แล้วตั้งชื่อไฟล์เป็น:

```text
birthday-voice.mp3
```

หลังอ่านจดหมายแล้วเลื่อนลงไปหน้าเลือกหัวข้อ จะมีเมนูให้เลือกวิดีโอ เสียงอวยพร และเป่าเค้ก เมื่อกดหัวข้อใด ระบบจะเปิดหัวข้อนั้นเป็นหน้าเดี่ยวทันที

หน้าเสียงอวยพรใช้ภาพเทปคาสเซ็ตแบบ CSS วงล้อจะหมุนตอนกดเล่นเสียง

## ระบบเป่าเค้ก

หน้าเป่าเค้กเปลี่ยนเป็นซอฟคุกกี้ก้อนใหญ่ มีปุ่มจุดไฟที่เทียน ช่องเขียนคำขอพร ปุ่มส่งคำขอพร และปุ่มเป่าเทียน เมื่อเป่าแล้วเทียนจะดับและแสดงข้อความ:

```text
ขอให้คำขอของน้องเป็นจริงทุกประการ
```

## โทนเว็บ

เว็บใช้ธีมกระดาษเก่าและดอกไม้กระดาษ โดยมีภาพพื้นหลังหลัก:

```text
assets/paper-flowers-bg.png
```
